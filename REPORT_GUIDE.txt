ABSTRACT (Page 3) - 200 words
================================================================================

Emotion detection from human expressions has gained significant attention in
human-computer interaction, mental health monitoring, and customer sentiment
analysis. This project presents a Multimodal Emotion Detection System that
analyzes emotions from two distinct modalities: text and facial expressions.

For text-based emotion detection, we implemented and compared six models:
Logistic Regression, Support Vector Machine (SVM), XGBoost, Naive Bayes,
traditional TF-IDF approach, and a state-of-the-art HuggingFace Transformer
model (DistilRoBERTa). The transformer-based model achieved the highest accuracy
of 90%+, significantly outperforming traditional ML approaches (75-83%).

For facial emotion recognition, we developed a Deep Convolutional Neural Network
(DCNN) trained on the FER-2013 dataset with 28,709 images across seven emotion
classes. We also integrated DeepFace for pre-trained emotion analysis and
compared performance with Random Forest, XGBoost, and Logistic Regression on
flattened pixel features.

The system provides a FastAPI backend with a responsive web frontend, enabling
real-time emotion detection with model selection capability. Results demonstrate
that deep learning approaches significantly outperform traditional machine
learning methods for both modalities, with transformer models showing remarkable
performance in understanding contextual nuances in text.

Keywords: Emotion Detection, Deep Learning, NLP, Computer Vision, Multimodal

4.3 DATA PREPROCESSING (1 page)
-------------------------------

4.3.1 Text Preprocessing Pipeline:

Step 1: Lowercase Conversion
- Input: "I AM HAPPY"
- Output: "i am happy"

Step 2: URL Removal
- Regex: r'http\S+|www\S+'
- Removes web links

Step 3: Mention Removal
- Regex: r'@\w+'
- Removes @usernames

Step 4: Special Character Removal
- Regex: r'[^a-zA-Z\s]'
- Keeps only letters and spaces

Step 5: Whitespace Normalization
- Multiple spaces → single space

Step 6: TF-IDF Vectorization
- Max features: 5000
- N-grams: (1, 2) unigrams and bigrams

[GRAPH 3: Flowchart of text preprocessing]

4.3.2 Image Preprocessing Pipeline:

Step 1: Load Image
- Read using OpenCV

Step 2: Convert to Grayscale
- cv2.cvtColor(img, cv2.COLOR_BGR2GRAY)

Step 3: Face Detection
- Haar Cascades or RetinaFace

Step 4: Resize
- Resize to 48x48 pixels

Step 5: Normalization
- Pixel values: 0-255 → 0-1

Step 6: Data Augmentation (Training only)
- Rotation: ±15°
- Shift: ±15%
- Zoom: ±15%
- Horizontal flip

[GRAPH 4: Sample augmented images]

4.4.1 Text Models:

A. TF-IDF + Logistic Regression Pipeline:
   TfidfVectorizer(max_features=5000, ngram_range=(1,2))

B. TF-IDF + SVM Pipeline:

D. TF-IDF + Naive Bayes:

4.4.2 Facial Models:

A. DCNN Architecture:
   Input(48,48,1)
   → Conv2D(64,5,5) → BN → Conv2D(64,5,5) → BN → MaxPool → Dropout(0.4)
   → Conv2D(128,3,3) → BN → Conv2D(128,3,3) → BN → MaxPool → Dropout(0.4)
   → Conv2D(256,3,3) → BN → Conv2D(256,3,3) → BN → MaxPool → Dropout(0.5)
   → Conv2D(512,3,3) → BN → Conv2D(512,3,3) → BN → MaxPool → Dropout(0.5)
   → Flatten → Dense(256) → BN → Dropout(0.6)
   → Dense(128) → BN → Dropout(0.6)
   → Dense(7, softmax)

   Total Parameters: ~4 million

CHAPTER 6: CONCLUSION (Page 19) - 200-250 Words
================================================================================

This project successfully developed a Multimodal Emotion Detection System capable
of analyzing emotions from both text and facial expressions using multiple machine
learning and deep learning approaches.

For text-based emotion detection, we implemented and compared six models ranging
from traditional machine learning (Logistic Regression, SVM, XGBoost, Naive Bayes)
to state-of-the-art transformers (HuggingFace DistilRoBERTa). The transformer-based
model achieved the highest accuracy of 90.2%, demonstrating the power of
pre-trained language models in understanding contextual nuances in emotional
expressions. Traditional ML models achieved 62-83% accuracy, with Logistic
Regression being the best among them.

For facial emotion recognition, we developed a custom Deep Convolutional Neural
Network achieving 72.8% accuracy on the FER-2013 dataset's seven emotion classes.
We also compared performance with DeepFace (75.3%), OpenCV backend (68.5%), and
traditional ML approaches (43-55%). Results clearly showed that deep learning
is essential for learning spatial features from images.

The system was deployed as a FastAPI backend with a responsive web frontend,
enabling real-time emotion detection with model selection capability. The
WebSocket-based webcam integration allows for live facial emotion analysis.

Key findings include the significant performance gap between deep learning and
traditional ML (7-30%), the importance of pre-training, and the critical speed-
accuracy trade-offs in production systems. Class imbalance remains a challenge,
particularly for the disgust class in facial recognition.

This work contributes a comprehensive comparison framework and a deployable
multimodal system for emotion detection research and applications.
